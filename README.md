# 魔芋播放器 / Konjac Player

一个 Windows 桌面的多站点视频播放器：外壳像一个极简浏览器，把 B 站、抖音、快手、YouTube 等站点的
播放页放在同一个窗口的多个标签里，随时把其中一个标签丢进**置顶小窗**继续放，或者用**老板键**连画面
带声音一起藏掉。

> 立场：只做「播放」和「隐藏」。不破解会员、不绕过付费墙、不改站点的权限校验，
> 对页面**只加控件、不删功能**——站点自带的点赞、弹幕、进度条、字幕都原样保留。

## 功能

### 小屏：独立置顶小窗
- 顶栏的「小窗」按钮把当前页、侧栏标签行右侧的小图标把那一条，**原样搬**进一个无边框小窗：
  页面不重载，所以进度、登录态、弹幕都不丢；再点一次收回主窗口并暂停。
- 小窗右侧是一列独立竖栏（在视频外面，不压住画面）：✕ 收回、置顶、横屏/竖屏、播放/暂停、倍速、
  音量、上一集/下一集，纯符号 + 悬停中文说明，鼠标不动时自动淡出。
- 竖屏形状给抖音/快手这类上下滑的 feed，横屏形状给 B 站长视频；`设置 → 小窗默认比例` 决定初始形状。
- 短视频站点的翻页只在 feed 类站点生效，B 站、AcFun 这类普通播放页保持站点自己的键盘行为。
- 小窗命令失败时竖栏会染成警告色并把原因写进悬停文字，不会出现「按了没反应」。
- 站点自己的「全屏」（B 站那个按钮、双击画面）在小窗里变成「铺满小窗」：小窗不会被撑成盖住整个桌面的大窗，
  画面大小和它原来站的位置都会回来。

### 老板键
- 默认 `Ctrl+Shift+H`，在 `设置` 里可以录成任意组合键（全局生效，窗口没聚焦也认）。
- 按一下：先暂停、再静音、然后所有窗口（含小窗）消失；再按一下恢复原状。
- 它和「藏在右下角」是两回事：老板键是假装没人看视频，托盘是继续放声音。

### 藏在右下角（系统托盘）
- 开启后，点 ✕ 或 Alt+F4 把应用收进通知栏，视频声音继续放。
- 左键托盘图标唤回；右键菜单有「显示」「缩到右下角」「全部暂停并静音」「退出」。
- 第一次收进去时，Windows 可能把图标藏进右下角的 `^` 展开层里。

### 站点、标签与界面
- 站点库自己加：顶部菜单「站点」和侧栏是同一份列表，增删改走弹窗，删除有二次确认，支持批量删除。
- 内置默认 8 个站点（哔哩哔哩、抖音、快手、西瓜视频、AcFun、CCTV 直播、YouTube、Twitch），清空后自动回到默认。
- 站点页里点开的子链接、`target=_blank` 都在本窗口新标签里打开，不会掉到系统浏览器。
- 每个站点的登录态存在应用自己的 WebView2 数据目录里，重启后还在。
- 侧栏可折叠成一条图标栏、宽度可调；字体大小、菜单弹出位置、运行日志都在 `设置` 里。
- 浅色薄荷配色；`prefers-reduced-motion` 下动效自动收掉。

## 快速开始

### 环境
- Windows 10/11，装好 **WebView2 Runtime**（Win11 自带，Win10 需更新）
- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/tools/install) stable（`browser.rs` 用了 edition 2024，需要 Rust 1.85+）
- 首次 `tauri build` 需要 Microsoft C++ Build Tools（WebView2 链接期）

### 开发
```bash
npm install
npm run tauri dev     # 起 vite + 编译 Rust + 拉起窗口
```
改 `src/` 下的前端会热更新；改 `src-tauri/` 下的任何文件会触发 Rust 重新编译并重启应用（标签页会丢）。

```bash
npx tsc --noEmit      # 前端类型检查
cargo check           # 在 src-tauri/ 下执行
```

### 打包
```bash
npm run tauri build   # 产物在 src-tauri/target/release/ 与 .../bundle/
```

## 项目结构

```
src/
  App.tsx        外壳全部界面：顶栏、标签、站点树、设置页、小窗竖栏
  App.css        浅色主题与所有组件样式
src-tauri/src/
  lib.rs         应用装配：插件、窗口、全局快捷键、命令注册
  browser.rs     多 webview 布局、标签生命周期、小窗搬运、页面桥接脚本
  commands.rs    暴露给前端的 IPC 命令（全部转发到 browser，并回到主线程执行）
  menu.rs        原生菜单事件 → 前端
  tray.rs        通知栏图标与它的菜单
  settings.rs    settings.json 读写（增量 patch，不整档覆盖）
  state.rs       共享状态：标签表、小窗标签、日志尾
  error.rs       AppError：任何失败都带一句能直接给人看的中文
index.html       ?bar=1 时同一个包渲染成小窗竖栏
```

### 给改代码的人：三处必须对齐的数字
主窗口的页面区域由 Rust 算出，外壳由 CSS 画出，两边数字不一致就会出现「页面旁边露出一条壳」。
- `browser.rs` 的 `TOP_CHROME = 40` / `RIGHT_RAIL = 54` ↔ `App.tsx` 的 `TOP` / `RAIL`
- `browser.rs` 的 `SIDEBAR_MIN/MAX`（52–420）↔ `App.tsx` 的 `SIDE_MIN/SIDE_MAX`；
  写盘前 `save_settings` 会把宽度夹回这个区间并回写，所以文件里的数字就是页面真正拿到的数字
- `browser.rs` 的 `MINI_RAIL_W = 43` / `mini_shape()` ↔ `App.tsx` 的 `MINI_STRIP` / `MINI_LANDSCAPE` / `MINI_PORTRAIT`

## 配置与数据位置

- 设置：`%APPDATA%\com.videobroswer.app\settings.json`
- 站点登录与缓存：同目录下的 WebView2 用户数据目录

应用标识保留了 `com.videobroswer.app`（crate 名同理）。改掉它等于换目录，
已登录的站点会全部掉登录，所以别顺手重命名。

## 已知限制

- 只做了 Windows：布局、置顶小窗、托盘都依赖 Windows 下的 WebView2 行为。
- 站点改版可能让桥接的翻页/倍速/上下集失效；此时页面本身仍可正常手动操作。
- 部分站点（如 B 站）会对非常规窗口尺寸触发风控（412），遇到时刷新或换回主窗口即可。
- 不做下载、不做录屏、不做去广告、不做任何绕过会员限制的事。
